# AUTHORA Implementation Plan

> **Goal:** Build a production-grade AI-powered book builder and writing studio for fiction and non-fiction authors, deployable as standalone SaaS or integrated into Anakatech ecosystem.

> **Architecture:** Monorepo with Next.js frontend (App Router), FastAPI backend, PostgreSQL + Redis, Docker Compose for local/cloud deployment. Clean modular architecture with domain-driven design.

> **Tech Stack:** Next.js 14, TypeScript, Tailwind, shadcn/ui, TipTap, FastAPI, SQLAlchemy, Alembic, PostgreSQL, Redis, Docker, Pydantic, python-docx, reportlab, ebooklib

## Database Schema (PostgreSQL)

```sql
-- Core
users (id, email, hashed_password, display_name, created_at, updated_at)
sessions (id, user_id, token_hash, expires_at)
projects (id, user_id, name, created_at)
books (id, project_id, title, genre, type [fiction|nonfiction], planner_data jsonb, created_at)
chapters (id, book_id, title, sort_order, content jsonb, word_count, created_at)
notes (id, book_id, user_id, title, content, created_at)

-- Gamification
user_stats (user_id, total_words, current_streak, longest_streak, xp, level)
achievements (id, user_id, type, earned_at)
goals (id, user_id, book_id, target_words, deadline, completed_at)
streak_logs (id, user_id, date, words_written)

-- System
audit_logs (id, user_id, action, resource, details jsonb, created_at)
settings (key, value jsonb)
```
