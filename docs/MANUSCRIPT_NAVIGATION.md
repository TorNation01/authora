# Manuscript Navigation

The manuscript workspace provides clear navigation and organization for book structure.

## Sidebar

- **Chapter list**: All chapters in sort order
- **Active indicator**: Current chapter highlighted
- **Word count**: Per chapter
- **Status badge**: Draft, Revising, Review, Done

## Chapter Actions

- **Select**: Click to open in editor
- **Reorder**: Drag handle to reorder (persisted via API)
- **Context menu** (⋮): Rename, Duplicate, Delete

## Quick Add

- **Add chapter**: Button at bottom of sidebar
- **Default title**: "Chapter N"
- **Content**: Empty paragraph

## Project Links

- **← Book title**: Back to project
- **Ghostwriter**: AI-assisted drafting
- **Edit & Polish**: Editorial tools
- **Fiction/Non-fiction workspace**: Plan and structure
- **Enter Finish Mode**: When eligible

## Find & Replace

- **Scope**: Current chapter or whole manuscript
- **Manuscript search**: Lists chapters with matches; click to jump
- **Replace**: Applies to current chapter (switch chapter to replace elsewhere)
