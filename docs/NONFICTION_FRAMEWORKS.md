# Non-Fiction Frameworks

AUTHORA supports these non-fiction frameworks at launch.

## Problem → Solution → Result

**Slug**: `problem_solution_result`  
**Ideal for**: Self-help, business, how-to  
**Genres**: Self-Help, Business, How-To

### Planning stages
- Reader Pain/Problem → Why It Matters → Root Cause/Context → Proposed Solution → Implementation Path → Expected Result/Transformation

### Outputs
- Promise/outcome map, chapter purpose map
- CTA/action-step prompts, credibility prompts
- Revision checklist for clarity and persuasion

---

## Step-by-Step Transformation

**Slug**: `step_by_step`  
**Ideal for**: Self-help, coaching, transformation books  
**Genres**: Self-Help, Health, Finance, Personal Development

- Start State → End State → Sequential Stages → Obstacles → Mindset Shifts → Action Steps
