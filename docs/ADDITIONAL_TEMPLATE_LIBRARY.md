## Planning Sections

- **Script:** Logline, characters, three-act structure, scene outline, dialogue notes
- **Speech:** Audience, purpose, key points, opening, closing, timing
- **Content transform:** Source material, unifying theme, structure, gaps to fill
- **Faith:** Scripture, theme, structure, illustrations, application
- **Children:** Age range, premise, characters, structure, page/spread notes
- **Life story:** Subject, sources, timeline, themes, voice
