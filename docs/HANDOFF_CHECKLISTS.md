# Handoff Checklists

Handoff checklists help you move from writing completion into the next stage—editing, beta reading, client delivery, self-publishing, or submission. Use them before exporting or sharing your manuscript.

## Checklist Types

| Checklist | When to Use | Export / Package |
|-----------|-------------|-------------------|
| [Before exporting a clean manuscript](#before-exporting-a-clean-manuscript) | Final polish before submission or editing | Clean manuscript (DOCX/PDF) |
| [Before sending to beta readers](#before-sending-to-beta-readers) | Ready to share with beta readers | Beta reader package |
| [Before sending to an editor](#before-sending-to-an-editor) | Ready for professional edit | Editor review copy |
| [Before submitting sample chapters](#before-submitting-sample-chapters) | Querying agents or publishers | Sample chapters export |
| [Before delivering a ghostwritten draft](#before-delivering-a-ghostwritten-draft) | Client handoff | Ghostwriter delivery package |
| [Before preparing for self-publishing](#before-preparing-for-self-publishing) | Going indie | Print-friendly draft, metadata |
| [Print-draft checklist](#print-draft-checklist) | Physical review or print prep | Print-friendly draft (PDF) |

## Print-Draft Checklist

Use this when preparing a manuscript for physical review or print.

### Formatting

- [ ] **Print-friendly format** – Appropriate margins, font size, spacing
- [ ] **Chapter breaks** – Each chapter starts on a new page
- [ ] **Page breaks** – No awkward breaks mid-scene

### Content

- [ ] **Clean manuscript** – No notes or comments
- [ ] **Front matter** – Title page, copyright, dedication, epigraph
- [ ] **Back matter** – Acknowledgements, about author (if including)

### Export

- [ ] **Print-friendly draft** (PDF) exported
- [ ] **Trim size** – Consider 5.5"×8.5" or 6"×9" for print-on-demand

**Export:** Print-friendly draft (PDF)

## Before Exporting a Clean Manuscript

Use this when you want a polished, submission-ready or editing-ready export.

### Export Readiness

- [ ] Run **Export readiness check** (Preview export) and address any errors
- [ ] No empty chapters or placeholder text
- [ ] Unresolved comments resolved or excluded from export
- [ ] Duplicate chapter headings fixed

### Content

- [ ] Manuscript is complete or at the stage you intend
- [ ] Notes and highlights excluded (clean export)
- [ ] Chapter order final

### Front Matter

- [ ] Title page included
- [ ] Copyright notice added (if applicable)
- [ ] Dedication and epigraph (optional) complete

### Metadata

- [ ] Book title set
- [ ] Author name set (or pen name)

**Export:** Clean manuscript (DOCX) or Clean manuscript (PDF)

---

## Before Sending to Beta Readers

Use this when preparing a package for beta readers.

### Manuscript

- [ ] Clean manuscript export (no notes, no revision marks)
- [ ] All chapters included or intentionally excluded
- [ ] Synopsis generated and included

### Package Contents

- [ ] Manuscript (DOCX)
- [ ] Synopsis
- [ ] Chapter summaries (optional but helpful)
- [ ] Feedback form or questions for readers

### Instructions

- [ ] Brief note on what feedback you want (plot, pacing, characters, etc.)
- [ ] Deadline for feedback (if any)

**Export:** Beta reader package (ZIP)

---

## Before Sending to an Editor

Use this when handing off to a developmental or copy editor.

### Manuscript

- [ ] Clean manuscript or review copy (depending on editor preference)
- [ ] Table of contents included
- [ ] Chapter breaks in place

### Supporting Materials

- [ ] Synopsis
- [ ] Chapter summary sheet
- [ ] Author bio draft
- [ ] Any style notes or preferences

### Front/Back Matter

- [ ] Acknowledgements drafted (if including)
- [ ] About the author drafted

### Communication

- [ ] Brief handoff note: timeline, goals, any specific concerns

**Export:** Editor review copy (DOCX) + Chapter summary sheet + Synopsis

---

## Before Submitting Sample Chapters

Use this when querying agents or publishers with sample chapters.

### Content

- [ ] First 3 chapters (or requested sample) polished
- [ ] Opening hooks strong
- [ ] No placeholder text or empty sections

### Package

- [ ] Sample chapters (DOCX)
- [ ] Synopsis
- [ ] Query letter (prepared separately)

### Metadata

- [ ] Title and author correct
- [ ] Word count accurate

**Export:** Sample chapters (DOCX)

---

## Before Delivering a Ghostwritten Draft

Use this when delivering a ghostwritten manuscript to a client.

### Manuscript

- [ ] Clean manuscript (no internal notes)
- [ ] Client’s preferred formatting applied
- [ ] All requested chapters included

### Delivery Package

- [ ] Manuscript (DOCX)
- [ ] Synopsis
- [ ] Chapter summaries
- [ ] Back cover blurb draft
- [ ] Author bio draft
- [ ] Handoff notes for client/editor

### Quality

- [ ] Client brief and preferences met
- [ ] Voice and tone consistent
- [ ] No placeholder or [TK] text remaining

**Export:** Ghostwriter delivery package (ZIP)

---

## Before Preparing for Self-Publishing

Use this when moving toward indie/self-publishing.

### Manuscript

- [ ] Clean manuscript or print-friendly draft
- [ ] Front matter complete (title, copyright, dedication, etc.)
- [ ] Back matter complete (acknowledgements, about author, etc.)

### Metadata Preparation

- [ ] Title and subtitle final
- [ ] Author name / pen name
- [ ] ISBN (if applicable)
- [ ] Categories and keywords
- [ ] Back cover blurb

### Format-Specific

- [ ] **Print:** Print-friendly draft exported, trim size considered
- [ ] **Ebook:** Ebook-friendly format exported
- [ ] **Workbook:** Printable layout with prompt-friendly spacing

**Export:** Print-friendly draft (PDF), Clean manuscript (DOCX), or Workbook export (PDF)

## Metadata Preparation Prompts

Use these prompts to complete metadata before export:

- **Title:** Is the title final? Any subtitle?
- **Author:** Legal name, pen name, or both?
- **Copyright:** Year and rights holder?
- **Dedication:** Who is this book for?
- **Epigraph:** Opening quote and attribution?
- **Acknowledgements:** Who to thank?
- **About the author:** Short bio for back matter or marketing?

---

## Front/Back Matter Completion Prompts

### Front Matter

- **Title page:** Title, subtitle, author
- **Copyright:** © [Year] [Name]. All rights reserved.
- **Dedication:** One line or short paragraph
- **Epigraph:** Quote and source
- **Preface / Introduction:** Context for the reader

### Back Matter

- **Acknowledgements:** Thank-yous
- **About the author:** Bio (50–150 words typical)
- **Resources:** Further reading, links, appendix
- **Glossary:** Terms (for non-fiction)
