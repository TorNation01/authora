# AUTHORA E2E Flow Scenarios

Launch-critical end-to-end flow tests. Implement in Playwright (`apps/web/e2e/`).

## A. New Writer Flow

1. Signup
2. Onboarding (if shown)
3. Create first project
4. Select template
5. Write first chapter
6. Use AI assist
7. Save draft
8. Export manuscript

## B. Returning Writer Flow

1. Login
2. Resume chapter
3. Edit content
4. Use notes/comments
5. Continue project
6. Enter Focus Mode
7. Hit milestone

## C. Fiction Guided Flow

1. Create fiction project
2. Choose framework
3. Use character/world tools
4. Write chapters
5. Track milestones
6. Export clean draft

## D. Non-Fiction Guided Flow

1. Create non-fiction project
2. Choose framework
3. Use research vault
4. Generate outline support
5. Write chapter
6. Export review copy

## E. Freeform Writing Flow

1. Create freeform project
2. Disable genre guidance
3. Write without framework
4. Use goals, notes, AI, export

## F. Collaboration Flow

1. Invite editor
2. Editor adds comments
3. Owner reviews comments
4. Approve chapter
5. Export review copy

## G. Billing Flow

1. Upgrade to paid tier (Stripe checkout)
2. Entitlement applies
3. Admin gift override
4. Promo code redemption
5. Expiry/reversion logic

## H. Deployment Flow

1. Bootstrap
2. Setup wizard
3. Health checks
4. Domain-live verification
5. Backup
6. Restore
7. Update
8. Rollback readiness
