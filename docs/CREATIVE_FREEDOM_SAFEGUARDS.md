# Creative Freedom Safeguards

User-facing safeguards that protect creative choices from over-policing by the Story Integrity Engine.

## Philosophy

The engine is designed to **support** writers, not to enforce a single template. It should:

- Flag clear gaps (empty chapters, placeholders) with high confidence
- Suggest improvements for speculative issues with lower confidence
- Always offer "Mark as intentional" for creative choices

## Guidance Mode

Writers choose their relationship to structure:

| Mode | Best for |
|------|----------|
| **Guided** | Writers who want strong structure feedback and framework alignment |
| **Flexible** | Writers who want lighter feedback; literary, experimental, or hybrid work |
| **Freeform** | Writers who want minimal feedback; only clear gaps |

## "Mark as Intentional"

Every issue that could reflect a creative choice includes a fix suggestion:

| Action | Label examples |
|--------|----------------|
| `mark_intentional` | "Mark as intentional (open/unresolved ending)" |
| | "Mark as intentional (spare opening is deliberate)" |
| | "Mark as intentional (minor/cameo character)" |
| | "Mark as intentional (series/open threads)" |
| | "Mark as intentional (slow-burn/deliberate pace)" |
| | "Mark as intentional (symbolic/brief motif)" |
| | "Mark as intentional (immersive/fragmentary style)" |
| | "Mark as intentional (lyrical/fragmentary style)" |
| | "Mark as intentional (unconventional module design)" |
| | "Mark as intentional if brief by design" |

## What the Engine Does Not Do

- **Does not** treat ellipsis as placeholder
- **Does not** treat rhetorical questions as errors
- **Does not** require all threads to resolve (series, open endings)
- **Does not** require formulaic transitions (lyrical nonfiction)
- **Does not** require explicit reflection markers (immersive memoir)
- **Does not** require exercises in every workbook chapter
- **Does not** punish short chapters in literary fiction
- **Does not** punish slow pacing in slow-burn or thriller

## Language Principles

- **Supportive**: "Consider adding" not "You must add"
- **Optional**: "May benefit from" not "Needs"
- **Context-aware**: Labels explain *why* something might be intentional
- **Non-prescriptive**: Suggestions, not requirements

## When to Use Each Mode

- **Guided**: First draft, genre fiction, textbooks, workbooks with clear structure
- **Flexible**: Literary fiction, memoir, hybrid projects, experimental structure
- **Freeform**: Early drafting, discovery writing, writers who prefer minimal feedback
