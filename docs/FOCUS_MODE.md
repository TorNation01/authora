# Focus Mode

Focus Mode provides a distraction-reduced writing environment.

## Features

- **Minimal UI**: Hides manuscript sidebar, toolbar controls, and right panels
- **Large writing area**: Centered, max-width content area
- **Save status**: Compact bar with "Saving…", "Saved just now", or "Exit"
- **Quick exit**: One click to return to full workspace

## Behavior

- **Autosave**: Continues in background; no change to save behavior
- **Stats**: Word count and session stats still tracked
- **Recovery**: Draft recovery and sync-failed banners still shown if applicable

## Toggle

- **Enter**: Toolbar button (maximize icon) or "Focus" in Finish Mode header
- **Exit**: "Exit" link in the focus mode header bar

## Design

- Calm, minimal chrome
- No popups or interruptions
- Preserves author flow
