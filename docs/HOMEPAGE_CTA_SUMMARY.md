# Final CTA Summary

## Primary CTA

**Start Free**

Used in:
- Hero section
- Pricing Teaser section
- Final CTA section

Links to: `/register` (or app base URL when configured)

## Secondary CTAs

| Section | CTA | Action |
|---------|-----|--------|

| Pricing Teaser | View Pricing | Link to /pricing |
| Final CTA | Explore Pricing | Link to /pricing |

## CTA Hierarchy

1. **Start Free** — Primary conversion. No credit card. Free tier.
2. **See How It Works** — Reduces friction for users who want to understand before signing up.
3. **View Pricing / Explore Pricing** — For users ready to compare plans.

## Supporting Lines

- "For fiction and non-fiction writers who want more than a blank page."
- "Stop circling the idea. Start finishing the book."
- "Plan clearly. Write smoothly. Finish confidently."

## Conversion Path

1. Hero → Start Free (immediate signup)
2. Hero → See How It Works (scroll → learn → return to Start Free or Pricing)
3. Pricing Teaser → Start Free or View Pricing
4. Final CTA → Start Free or Explore Pricing

All CTAs emphasize low friction and clear value. No "Request demo" or "Contact us" as primary paths for the landing page.
