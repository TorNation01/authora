# AUTHORA Design System

## Brand Direction

- **Elegant** – Refined, uncluttered
- **Soft premium** – Warm neutrals, gentle accents
- **Calm creative energy** – Supportive, not overwhelming
- **Writing sanctuary** – A place to focus and create

## Typography

| Token | Size | Use |
|-------|------|-----|
| display-lg | 3rem | Hero headlines |
| display | 2.25rem | Page titles |
| display-sm | 1.875rem | Section titles |
| text-2xl | 1.5rem | Card titles |
| text-lg | 1.125rem | Subsections |
| text-base | 1rem | Body |
| text-sm | 0.875rem | Secondary, labels |
| text-xs | 0.75rem | Captions |

**Fonts:**
- **Sans**: Source Sans 3 – UI, labels, navigation
- **Serif**: Crimson Pro – Headlines, prose, writing

## Color Palette

- **Primary**: Warm amber/terracotta (28 65% 52%) – CTAs, accents
- **Background**: Warm off-white (40 25% 98%)
- **Foreground**: Dark warm gray (30 12% 12%)
- **Muted**: Soft gray for secondary text
- **Success**: Green for completions
- **Destructive**: Red for errors

## Spacing

4px base scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96

## Components

- **Card sanctuary**: Soft shadow, rounded-xl, hover lift
- **Card soft**: Muted background, no border
- **Button primary**: Primary color, shadow-sm
- **Button soft**: Primary/10 bg, primary text
- **Empty state**: Dashed border, centered, icon + CTA

## Accessibility

- Focus visible: 2px ring, offset
- Sufficient contrast (WCAG AA)
- Semantic HTML, labels on inputs
